Events are created via the website. Once logged in, you'll find **"Create New Event"** above the calendar. Click it to open the event creation wizard.

<Info>
	**Permissions**

	To create an event, the role `Event Planner` or higher is required.
</Info>

## General information

In the first step, the most important details of the event are set, including the title, time, and duration.

![First page of the event wizard](/images/events/events-erstellen/EventWizard-General-EN.png)

### Allow Sharing

By default, other communities using the Slotbot can add an event to their own calendar. This makes it visible to their members, who can then sign up for slots. Members of other communities can only sign up for slots that are not reserved for a specific community.

Disabling **sharing** restricts the event to your own calendar and Discord only. Communities that have reserved slots are exempt from this. They retain access to their reserved spots regardless of this setting.

### Hidden

A hidden event only appears in the calendar for people with the role `Event Planner` or higher. The direct link to the event remains accessible to everyone.

### Display image

The display image can be specified by providing an external image URL or by uploading your own image directly.

![Picture upload dialog](/images/events/events-erstellen/Slotbot-DE-EventWizard-ImageUpload.png)

## Description

An event can have two types of descriptions, which differ in length and visibility.

![Second page of the event wizard](/images/events/events-erstellen/EventWizard-Description-EN.png)

The **summary** supports basic text formatting, as known from Discord chats, and is limited to approx. 4,000 characters.

The **extended description**, on the other hand, supports far more characters and extensive formatting options, but is only visible on the website. External integrations like Discord only show the summary instead. This allows detailed information to be shared without being limited by Discord's character limit.

## Details

![Third page of the event wizard](/images/events/events-erstellen/EventWizard-Details-EN.png)

In the third step, you can fill in up to 23 freely named fields, each with a title and text. These fields are ideal for providing additional information in bullet-points, such as the meeting point, prerequisites or external links.

Community administrators can define [templates for these fields](/en/communities/event-standards) for each event type, providing a helpful starting point for event creators. Once a standard has been configured, it can be applied with a single click using the **"Add standard 'X' details"** button.

## Slotlist

![Fourth page of the event wizard](/images/events/events-erstellen/Slotbot-DE-EventWizard-Slotlist.png)

The slot list consists of groups (**squads**) and seats within those groups (**slots**). The order of the squads can be freely arranged; slots within a squad are sorted in ascending order by their slot number.

Once all slots in an event are filled, a reserve list opens automatically with space for up to 25% of the total number of slots. Anyone who signs up as a reserve will automatically move up as soon as a regular slot becomes available.
