<Frame hint={"To allow the bot to create events, it needs the \"Create Events\" permission."} caption={"A scheduled event in Discord"}>
	![A scheduled event in Discord](/images/integrationen/discord/events/Scheduled-Event-EN.png)
</Frame>

As soon as an event is [added to a Discord channel](/en/integrations/discord/bot-commands/add-event-to-channel), the Slotbot automatically creates a scheduled event in Discord. They are displayed above the channel list under the "Events" entry.

![Event button in Discord](/images/integrationen/discord/events/Discord-Channellist-Event-EN.png)

For more information about scheduled events, please refer to this [Discord support article](https://support.discord.com/hc/en-us/articles/4409494125719-Scheduled-Events).
