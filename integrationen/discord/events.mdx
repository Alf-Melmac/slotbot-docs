<Frame hint={"Damit der Bot Events anlegen kann, benötigt er die Berechtigung \"Events erstellen\"."} caption={"Ein geplantes Event in Discord"}>
	![Ein geplantes Event in Discord](/images/integrationen/discord/events/Scheduled-Event-DE.png)
</Frame>

Sobald ein Event einem Discord-Kanal [hinzugefügt](/integrationen/discord/bot-befehle/event-hinzufügen) wird, erstellt der Slotbot automatisch ein geplantes Event in Discord. Sie werden über der Kanalliste unter dem Eintrag "Events" angezeigt.

![Event-Schaltfläche in Discord](/images/integrationen/discord/events/Discord-Channellist-Event-DE.png)

Weitere Informationen zu geplanten Events findest du in diesem [Discord-Support-Artikel](https://support.discord.com/hc/de/articles/4409494125719-Geplante-Events).
